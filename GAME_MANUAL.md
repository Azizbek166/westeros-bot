## 1. O'YIN SSENARIYSI VA TARIXIY FON (LORE)

Qirol Robert Baratheon shubhali ov paytida vafot etdi. Poytaxt King's Landingdagi **Temir Taxt (The Iron Throne)** bo'shab qoldi. Qadimgi paktlar buzildi va butun Westeros qit'asi bo'ylab buyuk oilalar o'rtasida shafqatsiz hokimiyat kurashi — **Besh Qirol Urushi (War of the Five Kings)** boshlandi.

### O'yinchining O'rni va Missiyasi
Siz Westeros olamiga yangi Lord sifatida qadam qo'yasiz.
1. **Qasamyod:** 8 ta mintaqa va 50 ta afsonaviy xonadondan birini tanlaysiz.
2. **Qahramon:** Xonadoningizning eng kuchli generallari (Jon Snow, Jaime Lannister, Daenerys Targaryen, Oberyn Martell va boshqalar) bilan birlashasiz.
3. **Qurilish va Kuch:** Shaharlaringizdan tilla, oziq-ovqat va temir yig'ib, yengilmas armiya tuzasiz.
4. **Zabt etish:** 21 ta strategik qal'ani qamal qilib, xonadoningiz ta'sir doirasini kengaytirasiz.
5. **Buyuk Xavf (Endgame):** Shimoldan qish va **250,000 lik Tun Qiroli (White Walkers)** armiyasi bostirib keladi. Westeros xalqi birlashmasa, barcha lordlar halok bo'ladi.
6. **Taxt G'olibi:** King's Landing qal'asini egallab, 800+ nufuz (prestige) to'plagan eng qudratli lord Westerosning Yagona Qiroli deb e'lon qilinadi.

## 2. BOSHLANG'ICH TIZIM TALABLARI VA O'RNATISH

### 2.1. Minimal va Tavsiya etilgan Talablar
* **Python:** 3.10, 3.11 yoki 3.12
* **Operatsion Tizim:** Linux (Ubuntu 22.04 LTS tavsiya etiladi), Windows 10/11, macOS
* **Ma'lumotlar Bazasi:**
  * *Lokal/Sinov rejimi:* SQLite (WAL rejimida avtomatik ishlaydi, o'rnatish shart emas)
  * *Production (500+ player):* PostgreSQL 14+ va `asyncpg` drayveri

### 2.2. Kerakli Kutubxonalar (`requirements.txt`)
Bot ishlashi uchun quyidagi 5 ta asosiy asinxron kutubxona zarur:

```text
python-telegram-bot[job-queue]>=21.0,<23
sqlalchemy>=2.0.0
aiosqlite>=0.20.0
asyncpg>=0.29.0
python-dotenv>=1.0.0
```

#### Har bir kutubxonaning aniq vazifasi:
1. **`python-telegram-bot[job-queue]`**: Telegram API bilan eng so'nggi asinxron rejimda aloqa qiladi. `[job-queue]` qo'shimchasi orqali orqa fonda (background) har 10 soniyada yurish taymerlarini va har 1 soatda iqtisodiy resurslar tekshiruvini boshqaradi.
2. **`sqlalchemy>=2.0.0`**: Eng zamonaviy asinxron ORM. 14 ta ma'lumotlar jadvalini boshqaradi, SQL inyeksiyalardan to'liq himoyalaydi va yuqori tezlikdagi tranzaksiyalarni ta'minlaydi.
3. **`aiosqlite`**: Mahalliy kompyuterda dasturlash va sinash uchun hech qanday murakkab server o'rnatmasdan asinxron SQLite bazasini ishga tushiradi.
4. **`asyncpg`**: 500 dan 5,000 tagacha o'yinchilar bir vaqtning o'zida harakat qilganda PostgreSQL bilan soniyasiga o'n minglab so'rovlarni mikrosekundlarda bajaruvchi eng tezkor Python drayveri.
5. **`python-dotenv`**: Xavfsizlik uchun Bot Tokeni va Baza parollarini `.env` faylidan avtomatik o'qiydi.

### 5.4. Tosh-Qaychi-Qog'oz (RPS) Taktik Jang Formulalari
O'yinda shunchaki ko'p askarga ega bo'lish g'alabani kafolatlamaydi. Taktik ustunlik jang taqdirini hal qiladi:

```
                  ┌───────────────────────────────┐
                  ▼                               │
          🐎 OTLIQ (Cavalry)                      │
         /                  \                     │
 (+40%) /                    \ (-30%)             │
       ▼                      ▼                   │
🏹 KAMONCHI (Archers) ──► 🛡️ PIYODA (Infantry) ──► 🗡️ NAYZACHI (Spearmen)
       ▲          (+30%)      │          (+30%)   │
       │                      │                   │
       └──────────────────────┴───────────────────┘
```

#### Taktik Koeffitsiyentlar Jadvali:
* 🐎 **Otliqlar** 🏹 Kamonchilarga qarshi **+40% bonus** oladi (yugurib borib yo'q qiladi).
* 🗡️ **Nayzachilar** 🐎 Otliqlarga qarshi **+40% bonus** oladi (otlarni nayza bilan to'xtatadi).
* 🏹 **Kamonchilar** 🛡️ Piyodalarga qarshi **+30% bonus** oladi (masofadan o'qqa tutadi).
* 🛡️ **Piyodalar** 🗡️ Nayzachilarga qarshi **+30% bonus** oladi (nayza orasiga qalqon bilan yorib kiradi).

#### Jang Hisoblashning Matematik Formulalari:
1. **Hujumchi Umumiy Kuchi ($A_{total}$):**
   $$A_{total} = \left[ \sum_{i} (N_i \times ATK_i \times RPS_{bonus}) \right] \times \left(1 + \frac{\text{Hero Leadership}}{200}\right)$$
2. **Himoyachi Umumiy Kuchi ($D_{total}$):**
   $$D_{total} = \left[ \sum_{j} (G_j \times DEF_j \times RPS_{bonus}) \right] \times \left(1 + \frac{\text{Castle Defense}}{2500}\right)$$
3. **Talafotlar (Casualties):**
   * Agar $A_{total} > D_{total}$ bo'lsa: Hujumchi g'alaba qozonadi. Himoyachi garnizoni 80-100% qiriladi, hujumchi esa kuchlar nisbatiga mutanosib ravishda 10-40% askar yo'qotadi.
   * Agar $D_{total} \ge A_{total}$ bo'lsa: Qal'a mudofaasi g'alaba qozonadi. Hujumchilar qochadi yoki qiriladi.

### 5.5. Real-Time Yurish Taymeri (March Engine)
Hujum tugmasi bosilganda jang bir zumda yakunlanmaydi:
1. O'yinchi armiyasini tanlab qal'aga yurish boshlaganda ma'lumotlar bazasida `BattleMarch` yozuvi yaratiladi.
2. Yurish vaqti: **3 daqiqa (180 soniya)**.
3. Botning orqa fonidagi **10 soniyalik Asinxron Ticker (Tick Engine)** barcha faol yurishlarni nazorat qilib turadi.
4. Vaqt 0 ga yetishi bilan jang kalkulyatori ishga tushadi, g'olib aniqlanadi, qal'a egasi yangilanadi va ikkala tomonga ham batafsil **Harbiy Jangnoma (Battle Report)** yuboriladi.

## 8. SERVERNI SOZLASH, MONITORING VA XAVFSIZLIK

### 8.1. 500+ dan 5,000+ gacha O'yinchilar uchun PostgreSQL Sozlamalari
Production serverda PostgreSQL ishlatish uchun `postgresql.conf` da quyidagi parametrlar tavsiya etiladi:
```ini
max_connections = 300
shared_buffers = 1GB
effective_cache_size = 3GB
work_mem = 16MB
maintenance_work_mem = 256MB
wal_buffers = 16MB
checkpoint_completion_target = 0.9
```

### 8.2. Systemd Servisi orqali 24/7 Avtomatik Ishlatish (Linux Ubuntu)
`/etc/systemd/system/gotbot.service` faylini yarating:
```ini
[Unit]
Description=The Iron Throne Telegram MMORPG Bot
After=network.target postgresql.service

[Service]
Type=simple
User=root
WorkingDirectory=/var/www/got_bot
ExecStart=/var/www/got_bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Servisni yoqish va boshqarish:
```bash
sudo systemctl daemon-reload
sudo systemctl enable gotbot
sudo systemctl start gotbot
sudo systemctl status gotbot
```
